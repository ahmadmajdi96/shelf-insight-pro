# ALPHA IR — AI Shelf Intelligence Platform

AI-powered shelf image analysis for retail SKU detection, planogram compliance, and share of shelf analytics.

## Getting Started

### Prerequisites
- Node.js 20+ and npm

### Install & Run

```bash
npm install
npm run dev
```

## Docker Deployment

See [DOCKER.md](./DOCKER.md) for containerized deployment instructions.

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase (Auth, Database, Storage, Edge Functions)
